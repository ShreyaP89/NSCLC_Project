# Two-Stage Hierarchical Classification of Non-Small-Cell Lung Cancer Subtypes Using CT Radiomics Features
This project predicts the histological subtype of non-small cell lung cancer from radiomics features extracted from CT scans and tumor segmentations. The whole pipeline is in one Jupyter notebook, from feature extraction through harmonization, model training, cross-validation, external validation, and diagnostics. The model separates four classes, Adenocarcinoma, Squamous, Large-Cell, and NOS, and a second version with NOS removed is trained to test whether NOS cases blur the Adenocarcinoma and Squamous boundary. Radiomics was chosen over deep learning so that the selected features stay interpretable.
 
Training uses the NSCLC-Radiomics and NSCLC-Radiogenomics collections, with one scan kept per patient so near-duplicate scans cannot inflate scores. Of 513 candidate patients, 455 produced usable features. External validation uses TCGA-LUAD, TCGA-LUSC, and Lung-PET-CT-Dx, which contribute 101 patients. The data paths at the top of the notebook point to a local folder and need to be edited before running.
 
Features are extracted with PyRadiomics using 1 mm resampling and original, wavelet, and multi-scale Laplacian of Gaussian images, giving 1,781 features after cleaning. All collections are then harmonized together with ComBat, with subtype protected as a covariate so class signal is not removed along with scanner effects. Feature selection runs once on the full training set, outside the cross-validation folds, so every fold uses the same fixed feature set. Stage one selects up to 20 features with LASSO, a stepwise wrapper, or MARS, and stage two selects 10 features per class pair using Extra Trees importance. Correlated features are removed in both stages.
 
The classifier works in two steps. Stage one is a multinomial logistic regression that produces probabilities for every class. The two most likely classes then select a pairwise RBF SVM trained only on that pair, and its output replaces stage one's probabilities for those two classes while all other classes are set to zero. An optional confidence threshold of 0.70 flags low-confidence cases as uncertain and returns the ranked subtype probabilities instead of a single label.
 
Performance is measured with repeated stratified 5-fold cross-validation, using 10 repeats, and reported per class as precision, sensitivity, F1, specificity, one-versus-rest accuracy, and ROC-AUC. Average cross-validated ROC-AUC with NOS included is 0.977 for LASSO, 0.967 for MARS, and 0.965 for the wrapper. With NOS removed it is 0.982, 0.969, and 0.966. Because features are selected once on the full training set, cross-validated scores are likely somewhat optimistic. On the external collections the model did not generalize, with an average ROC-AUC around 0.45.
 
Much of the notebook after the main model is diagnostic work, each cell marked as diagnostic with its result. These cover stage one and stage two design choices, clinical feature tests, and site effects. The site effect checks show that a nonlinear model can still identify the source cohort after harmonization, and the external checks point to residual site effects and differences in segmentation protocol.
 
The notebook needs Python 3 with numpy, pandas, scipy, scikit-learn, statsmodels, matplotlib, seaborn, joblib, SimpleITK, pyradiomics, neuroHarmonize, py-earth, and patsy. Run it from top to bottom. Feature extraction is cached after the first run, the cross-validation cells run in parallel, and all random seeds are fixed at 42.
 
Site and class composition are confounded in the training data, and fully resolving this likely needs balanced data from more scanners. Future directions include adding clinical variables with more complete data, projecting new-site data into the existing harmonization space, and extending the hierarchy to finer subtypes within a class.
